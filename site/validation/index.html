    0.4 验证记录¶

    日期：2026-10-18。本地环境：Linux x86_64、Python 3.12.14、CMake 4.4.4、SWIG 4.5.1、JPype1 1.7.1、Temurin JDK 17.0.20.1 与 g++。

    自动测试¶

    完整测试套件 107 项通过，无跳过。测试包含完整进化、类型和初始化检查、程序 JSON 往返、Python/C++/Java 数值对照、Native-only 原语、评分缓存上下文变更、随机任务默认不缓存、任务工作计数，以及配置错误不会转为适应度惩罚。

    0.4 增加以下集成验证：

    • C++ 和 Java 在原生端完成整批回归评分。
    • 原生质点仿真与 Python 对照一致，重复评分与不同个体交替评分不泄漏状态。
    • 独立进程运行原生示例，覆盖 JVM 冷启动。
    • auto_build=False 时禁止调用构建函数，仍可从现有产物准备、执行完整 ProgramSpec。
    • Java 通过额外 classpath 加载用户任务；C++ 修改原生任务名称并重新构建，均无须修改 Python 适配器。
    • CTest 运行六个原生 C++ 测试；八个 Java 类各有可独立运行的测试主程序。

    所有 Python 源文件和示例有对应学习测试，所有原生实现文件有对应语言测试；测试全部位于 src 外的 tests/。

    回归进化¶

    任务：41 个均匀样本拟合 x*x+x，seed=42、population_size=30、generations=10，其余默认。

    后端 最优 MSE 实际评分调用 程序长度
    Python 0.0 228 14
    CMake/SWIG C++ 0.0 228 14
    JPype Java 0.0 228 14

    三个后端都因 target_fitness 达标停止；结果位于 validation/regression。run.json 的 metadata.task_work 单独记录实际样本计数。三个后端均为 9,348 个样本评分。

    完整控制仿真¶

    质点模型、积分与代价详见 完整任务，默认四回合、每回合 100 步。原始结果位于 validation/simulation.json。

    验证模式 Python / C++ / Java 结果 实际评分调用 环境步数
    手写反馈 a=-(x+v) 0.11759180440100887 1 400
    小预算进化，30 个体、10 代、seed=42 0.625 267 106,800

    该小预算进化运行验证了搜索与完整环境评分的连接，但没有学出优于零动作的控制器，结果弱于手写反馈。不能据此宣称控制学习效果良好。三个后端结果一致也不是加速比测量；本交付没有端到端性能基准或真实机器人验证。

    安装与文档¶

    验证 pip install -e .、开发依赖安装、Ruff 检查、MkDocs 严格构建、源码包与 wheel 构建。wheel 保留唯一的原生源码，独立安装后从安装路径导入，重新构建 C++/Java，并执行完整任务。ZIP 与源码分发包含学习测试，wheel 不包含测试。

    GitHub Pages 工作流随源码交付，仓库 Settings → Pages 选择 GitHub Actions 后可部署；本次未进行线上发布。只实测上述 Linux/Python 3.12 环境，CI 配置覆盖 Linux/Python 3.10、3.12、3.13，不表示这些环境已在本地执行。
